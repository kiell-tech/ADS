# ADS
🗄️ How to Import the Database in XAMPP Localhost

METHOD 1 — Using the Setup Script (Easiest ✅ Recommended)
This is the fastest way — no manual importing needed.

Step 1. Make sure your bulsu_voting folder is inside:
C:\xampp\htdocs\bulsu_voting\

Step 2. Open XAMPP Control Panel → Start Apache and MySQL

Step 3. Open your browser and go to:
http://localhost/bulsu_voting/setup.php

Step 4. You'll see a success page like this:
✅ Executed: bulsu_voting.sql
✅ Executed: triggers.sql
✅ Executed: procedures.sql
✅ Executed: views.sql
✅ Setup Complete!

Step 5. Click "Go to Login Page" — you're done!
